# Kiran Academy – Internship Task 1: Environment Setup & Basic Java Programs

**Student Name:** Vaishnavi Pise

## Project Description

This project is part of the Kiran Academy Internship Program (Task 1). It demonstrates the Java environment setup and contains six basic Java programs written in a single file, `Hello.java`:

1. Print Hello World
2. Addition of two variables
3. Subtraction (difference) of two variables
4. Multiplication of two variables
5. Division of two variables
6. Modulus of two variables

## Software Requirements

- Java Development Kit (JDK) 17, 21, or 25
- Any text editor or IDE (e.g., VS Code, IntelliJ IDEA, Eclipse)

Verify your installation:

```
java -version
javac -version
```

## How to Compile and Run

Open a terminal in this project folder and run:

```
javac Hello.java
java Hello
```

Expected output:

```
Hello World
Addition = 30
Difference = 10
Multiplication = 200
Division = 2
Modulus = 0
```
